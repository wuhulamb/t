出于以下原因，我创建了这里：

- 表达欲望强烈
- 不想打扰朋友圈
- 希望自己的文字可以自己管理
- **读/写简单、方便**

它很像博客，实际是一个类似微博或者小红书一样的产品，可以使用手机发送图文，自动构建生成网站，部署在 GitHub 上。

最后，不得不感慨 Agent 的进步速度超乎我的想象。本应用完全由 Agent 生成，包括安卓 APP 、方便电脑使用的 nodejs APP 、 Cloudflare Worker 、 GitHub Pages 仓库、直连网络和 Cloudflare Worker 的中转 VPS 配置。
